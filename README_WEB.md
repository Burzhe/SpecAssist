# SpecAssist Offline Web App

## Что это

`dist/` содержит автономное веб-приложение для импорта Excel и поиска по спецификациям. Оно работает полностью офлайн и не требует Python/Node/Docker на целевом ПК.

## Как пользоваться

1. Откройте файл `dist/index.html` двойным кликом (работает через `file://`).
2. Перетащите `.xlsx` файл на экран или выберите через кнопку.
3. Выберите листы для импорта и нажмите **«Импортировать и индексировать»**.
4. После завершения появится экран поиска с фильтрами и результатами.
5. Нажмите на строку результата, чтобы увидеть детали и похожие позиции.

## Сохранение состояния

Данные и индекс сохраняются в IndexedDB. После перезагрузки страницы импорт повторять не нужно.

## Сброс проекта

Нажмите кнопку **«Сбросить проект»** в правом верхнем углу, чтобы очистить IndexedDB и начать заново.
